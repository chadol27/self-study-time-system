# 스공시 좌석 및 출결 관리 시스템

학생의 좌석과 출결을 Google Spreadsheet와 웹 화면에서 관리하는 시스템입니다.

## 처음 사용할 때

1. 시스템 관리자로부터 대상 스프레드시트와 웹 앱 주소를 받습니다.
2. 스프레드시트를 새로 연 뒤 **스공시 관리 → 시트 초기화 및 검사**를 실행합니다.
3. `학생명단` 시트를 작성하고 **스공시 관리 → 학생 명단 적용**을 실행합니다.
4. 검사 결과에 오류가 있으면 안내된 학번, 좌석번호, 요일과 교시를 확인해 시트 값을 수정합니다.
5. 웹 앱에서 학생 로그인과 교사 로그인이 정상적으로 되는지 확인합니다.

## 학생명단 입력

`학생명단` 시트의 1행은 제목 행이며, 2행부터 전체 학생 정보를 입력합니다.

| 열 | 입력 내용 |
| --- | --- |
| A | 학번 |
| B | 이름 |
| C | 전화번호 뒤 4자리 |

학번과 전화번호 뒤 4자리는 텍스트로 입력합니다. 전화번호 뒤 4자리는 `0123`처럼 앞의 0을 포함한 정확한 네 자리여야 합니다. 명단을 수정한 뒤 **스공시 관리 → 학생 명단 적용**을 실행하면 유효한 학생 정보와 오류를 확인할 수 있습니다.

학생명단은 자정 일일 작업 때도 자동으로 다시 적용됩니다. 평소에는 캐시된 명단을 사용하며, 캐시가 만료되거나 필요한 학번이 캐시에 없을 때만 시트를 다시 읽습니다.

## 명부 입력

`명부` 시트의 1-2행은 제목 행이며, 학생 정보는 3행부터 한 명당 한 행에 입력합니다.

| 열 | 입력 내용 |
| --- | --- |
| A | 학번 |
| B | 좌석번호 |
| C:N | 월-목의 1-3교시 신청 여부 |
| O | 시스템이 자동 생성하는 내부 키 |
| P 이후 | 날짜별 1-3교시 출결 상태 |

이름과 전화번호 뒤 4자리는 `명부`에 입력하지 않습니다. O열은 시스템용이므로 직접 수정하지 않습니다.

### 신청 여부 숫자

`명부` 시트 C:N열에는 각 요일과 교시의 신청 여부를 입력합니다.

| 값 | 의미 |
| --- | --- |
| 빈 값 | 미신청 |
| `0` | 미신청 |
| `1` | 신청 |

`0`, `1`, 빈 값 이외의 값은 입력하지 않습니다.

같은 요일에는 교시가 달라도 두 학생이 같은 좌석을 사용할 수 없습니다. 서로 다른 요일의 좌석 공유는 가능합니다. 충돌 학생은 오류를 해결할 때까지 모든 요일의 교사 좌석에서 제외됩니다.

### 출결 상태 숫자

`명부` 시트 P열 이후의 날짜별 출결 칸에는 다음 값이 표시됩니다.

| 값 | 의미 | 교사 화면 표시 |
| --- | --- | --- |
| 빈 값 | 미래 출결이 아직 확정되지 않았거나 해당 교시 미신청 | 신청 학생은 흰색 신청함, 미신청은 회색 |
| `0` | 기존 자료의 미확정 또는 미신청 값으로, 빈 값과 동일 | 빈 값과 동일 |
| `1` | 신청함 | 현재 교시 신청이면 흰색, 미신청이면 회색 |
| `2` | 출석함 | 초록색 |
| `3` | 결석함 | 빨간색 |
| `4` | 학생이 미리 등록한 결석 | 주황색 |

출결값은 가급적 웹 앱에서 변경합니다. 시스템이 당일 신청 교시에 기록하는 신청 상태 `1`은 `기록` 시트에 남지 않으며, 학생이나 교사가 직접 변경한 내용만 기록됩니다. 기존 출결값은 변환하지 않고 위의 새 의미로 그대로 해석합니다.

학생 또는 교사가 여러 교시나 여러 결석일을 한 번에 변경하면 출결 셀과 `기록` 시트 행을 범위 단위로 저장합니다. 각 교시의 변경 이력은 기존과 동일하게 별도 행으로 유지됩니다.

## 학생 사용 방법

1. 웹 앱에서 **학생용**을 선택합니다.
2. 학번과 전화번호 뒤 4자리로 로그인합니다.
3. 상단에서 본인의 좌석번호와 월-목 교시별 정기 신청 현황을 확인합니다. 오늘부터 30일 후까지 결석할 날짜 또는 기간을 선택해 등록합니다.
4. 본인이 등록한 사전 결석 날짜를 목록에서 확인하고, 취소할 날짜를 선택해 한 번에 취소할 수 있습니다. **전체 선택** 버튼은 취소 가능한 날짜를 모두 선택하며, 선택 후에는 같은 버튼으로 전체 해제할 수 있습니다. 목록에는 교시를 별도로 표시하지 않습니다.
5. 사용을 마치면 로그아웃합니다. 로그아웃하면 학생 로그인 화면으로 돌아갑니다.

금요일부터 일요일과 `설정` 시트에 등록된 미운영일은 결석 등록 대상에서 자동으로 제외됩니다. 당일 변경은 1교시 시작 시각 전까지만 가능하며, 마감 후 시작일과 종료일은 내일부터 선택됩니다. 교사가 지정한 출석과 결석은 학생이 취소할 수 없습니다. 학생 로그인은 로그인 시점부터 5분간 유지되며 활동해도 연장되지 않습니다. 학생 키와 만료 시각은 현재 페이지의 JavaScript 변수에만 저장되므로 페이지를 새로고침하면 다시 로그인해야 합니다.

## 교사 사용 방법

1. 웹 앱에서 **교사용**을 선택하고 교사 비밀번호를 입력합니다.
2. 날짜와 교시를 선택해 좌석별 출결 상태를 확인합니다. **오늘 운영일만 수정 가능**하며, 과거와 향후 30일 날짜는 조회만 가능합니다.
3. 좌석 본문을 눌러 여러 학생을 선택합니다. 우측 상단 정보 아이콘을 누르면 학생 정보, 월-목 전체 신청 요일과 교시, 현재 출결 상태가 표시됩니다. 모든 교시를 신청한 요일은 `월`, 일부 교시는 `수1-2`, `목1`과 같이 표시됩니다.
4. 좌석 배치 위에 항상 표시되는 버튼 메뉴에서 **출석**, **결석**, **되돌리기**를 선택해 일괄 적용합니다. **신청자 전체 선택**은 현재 교시 정기 신청자만 추가 선택하며 기존 미신청 개별 선택은 유지합니다. 신청자가 모두 선택되면 **전체 해제**로 바뀌며 미신청 개별 선택까지 모두 해제합니다. 신청자가 없는 교시에도 개별 선택이 있으면 전체 해제가 가능하고 선택도 없으면 버튼이 비활성화됩니다.
5. 사용을 마치면 로그아웃합니다. 교사 페이지의 **메인**을 눌러 돌아가도 자동으로 로그아웃됩니다.

메뉴나 각 페이지의 메인 링크를 누르면 대상 화면이 표시될 때까지 로딩 안내가 나타납니다. 교사 페이지는 최초 인증과 설정 확인 중 `불러오는 중...`을 표시하며, 좌석 데이터를 불러오는 동안 좌석 선택과 변경 기능을 사용할 수 없습니다.

해당 요일에 한 교시라도 신청한 학생은 모든 교시에 좌석에 표시됩니다. 현재 교시 미신청이면 빈 값·`0`·`1`은 회색 **해당 교시 미신청**으로 표시되며 개별 선택하여 출석 처리할 수 있습니다. 기존 미신청 `1`은 조회나 자동 처리로 수정하지 않습니다. 출석 `2`, 결석 `3`, 사전 결석 `4`는 신청 여부와 관계없이 각각 초록색, 빨간색, 주황색입니다. 그 요일에 전혀 신청하지 않은 학생은 아래 별도 미신청자 기능을 사용합니다.

교사의 출석·결석·되돌리기는 **선택한 교시만 변경**하며 이후 교시에는 영향을 주지 않습니다. 결석은 현재 교시 정기 신청자의 `1`과 모든 출석 `2`만 `3`으로 바꿉니다. 회색 미신청 상태에서 결석을 누르면 변경하지 않으며, 출석 처리 후에는 결석으로 변경할 수 있습니다. 되돌리기는 정기 신청 교시를 `1`, 미신청 교시를 빈 값으로 복원하고 숫자 `0`을 저장하지 않습니다. 결석과 되돌리기는 사전 결석 `4`를 유지하며 출석은 `4`도 `2`로 변경할 수 있습니다. 학생 사전 결석과 자동 신청 처리는 기존처럼 신청 교시만 대상으로 합니다. 교사 로그인은 한국 시간 기준 자정이 지나면 만료됩니다.

### 미신청자 목록

교사 화면에는 검색 결과와 처리 상태·오류를 표시하며, 검색 전 기본 안내와 미신청자 운영 규칙에 대한 상시 설명 문구는 표시하지 않습니다. 안내 문구 제거에 따른 설정이나 운영 절차 변경은 없습니다.
검색 결과는 학번과 이름만 표시되며, 해당 버튼을 누르면 선택한 교시에 추가·출석 처리됩니다.
학생 목록의 행 배경은 현재 교시 기준으로 출석은 초록색, 결석은 빨간색, 기록 없음은 흰색입니다. 선택해도 출결색은 유지되며 파란 테두리와 체크박스로 선택을 구분합니다.

좌석 아래에서 학번·이름을 검색해 오늘 참여 학생을 추가합니다. 정기 신청자도 추가할 수 있지만 **좌석과 목록은 별도 출결 기록**입니다. 정상 학생명단에 있는 학생만 검색되며 전화번호 형식 오류 등은 먼저 명단에서 수정합니다. 검색 명단은 현재 페이지 메모리에만 저장하므로 명단 변경 후에는 페이지를 새로고침합니다.

- 추가하면 현재 교시만 즉시 출석으로 표시하고 백그라운드 저장합니다. 다른 작업을 계속할 수 있으며 저장 중·실패 표시를 확인하세요. 이미 있는 학생을 다시 추가해도 현재 교시만 출석으로 변경됩니다.
- 추가된 학생은 그날 모든 교시에 표시됩니다. 목록 전용 선택·전체 선택·출석·결석·되돌리기 버튼을 사용합니다. 되돌리기는 해당 교시를 `기록 없음`으로 비웁니다.
- 추가 외 변경은 응답을 기다리는 동안 목록 조작이 제한됩니다. 여러 학생은 학생별로 저장되므로 일부 실패 시 실패한 학생만 확인합니다.
- 세 교시를 모두 되돌려 빈 상태로 만든 학생만 목록에서 제거할 수 있습니다.
- 저장 실패 시 **같은 요청 재시도**를 사용합니다. 다른 교사와 충돌하면 최신 상태를 확인하고 다시 승인합니다. **서버 다시 읽기 · 대기 취소**는 확인 후 미저장 대기 작업을 버립니다.
- 저장 중 페이지를 떠나면 이미 보낸 요청은 저장될 수 있지만 대기 작업은 사라집니다. 저장 완료를 확인한 뒤 종료하는 것을 권장합니다.

`미신청자` 시트는 초기화 시 자동 생성됩니다. 실제 첫 저장 때 날짜당 4열을 시간순으로 생성하며 1행은 실제 날짜, 2행은 `학번 / 1교시 / 2교시 / 3교시`, 3행부터 학생 목록입니다. 날짜별 학번 목록은 독립적이고 같은 날짜에는 학번당 한 행입니다. 상태는 빈 값, 출석 `2`, 결석 `3`만 사용합니다. 미운영일로 변경해도 이 시트의 기록은 자동 삭제하지 않습니다.

이름은 현재 학생명단에서 읽습니다. 명단 삭제·오류 시 `학생 정보 확인 불가`로 표시하고 출결은 보존합니다. `기록` 시트에서는 내부 키 `extra:학번`으로 구분하므로 학번을 다른 학생에게 재사용하지 않습니다. 학생 로그인 허용 범위는 종전 그대로이며, 이 목록에 추가했다고 학생 로그인이 새로 허용되지는 않습니다.

### 변경 후 운영 확인

요일별 좌석 정책 반영 시 기존에 같은 요일의 서로 다른 교시로 나누어 공유하던 좌석도 중복 오류가 됩니다. 배포 후 **시트 초기화 및 검사**에서 확인하고 아래 학생 정보 변경 절차에 따라 명부를 수정합니다. 기존 출결 데이터의 자동 변환이나 새 설정 추가는 없습니다. 다른 요일의 좌석 공유는 그대로 허용됩니다.

실제 웹 앱에서 한 교시 신청자가 모든 교시에 보이는지, 회색 미신청의 출석 후 결석 및 빈 값 복원, 신청자 전체 선택과 미신청 개별 선택의 유지·전체 해제를 확인합니다. 신청자 0명인 교시의 해제 버튼, 충돌 학생의 모든 요일 제외, 과거·미래 변경 차단도 점검합니다.

새 코드 반영 후 **시트 초기화 및 검사**를 실행합니다. 새 필수 Script Properties나 트리거는 없습니다. `EXTRA_`로 시작하는 속성은 재시도·충돌 방지를 위해 자동 관리하므로 직접 삭제하지 않습니다. 미완료 저장은 다음 미신청자 요청에서 안전하게 이어서 처리합니다. 직접 시트 편집 등으로 복구할 수 없다는 오류가 나면 시트와 기록, 해당 미완료 속성을 백업하고 대조한 뒤 복구해야 합니다.

실제 웹 앱에서 추가 중 교시 전환, 같은 학생의 추가 후 결석, 실패 재시도, 두 교사 동시 변경, 빈 교시만 남은 학생 제거를 점검하세요. 기존 좌석은 오늘의 선택 교시만 바뀌는지, 학생 화면은 정기 신청 현황을 표시하면서 미래 결석 등록을 유지하는지 확인합니다.

## 학생 정보 변경

한번 사용한 명부 행의 학번은 직접 고치지 않습니다. 신청 정보 변경이 필요하면 기존 행의 C:N 신청값을 모두 비운 뒤 새 행을 추가합니다. 이름이나 전화번호 뒤 4자리를 바꿀 때는 `학생명단`을 수정하고 **학생 명단 적용**을 실행합니다. 신청값이 모두 빈 기존 행은 과거 출결 보관용으로 유지합니다.

### 기존 명부 전환

이전 구조의 `명부`는 자동 변환되지 않습니다. 스프레드시트를 먼저 백업한 뒤 B열의 이름과 D열의 전화번호 뒤 4자리를 `학생명단`으로 옮기고, 기존 B열과 D열을 직접 삭제해 새 열 구조에 맞춥니다. 이후 **학생 명단 적용**과 **시트 초기화 및 검사**를 차례로 실행합니다.

## 미운영일 관리

`설정` 시트에서 다음과 같이 입력합니다.

| 열 | 입력 내용 |
| --- | --- |
| A | 미운영 날짜 |
| B | 사유 |

A열은 텍스트가 아닌 실제 날짜값으로 입력합니다. 새로 등록한 미운영일은 학생의 결석 등록과 교사의 출결 대상에서 제외됩니다. 오늘부터 30일 후 사이에 이미 만들어진 `명부`의 해당 날짜 출결 열은 자동 처리 시 삭제되지만, 과거 출결 열과 `미신청자` 기록은 삭제되지 않습니다.

## 운영 시 주의사항

- 프로젝트와 스프레드시트의 시간대는 모두 `Asia/Seoul`로 유지합니다.
- 같은 요일에는 교시가 달라도 좌석번호가 겹치지 않도록 입력 후 **스공시 관리 → 시트 초기화 및 검사**를 실행합니다.
- 날짜별 출결 열과 숨겨진 내부 키는 직접 추가하거나 수정하지 않습니다.
- 날짜 제목에는 연도가 포함되므로 새해가 되어도 기존 출결 열을 삭제할 필요가 없습니다.
- 자료를 별도로 보관하려면 스프레드시트 전체를 복사합니다.
