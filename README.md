# 스공시 좌석 및 출결 관리 시스템

Google Spreadsheet와 Apps Script 웹 앱으로 학생 좌석과 출결을 관리합니다.
세부 구현 정책과 테스트 기준은 [`DETAILS.md`](DETAILS.md)를 참고합니다.

## 시작하기

1. `pnpm install`을 실행합니다.
2. 대상 스프레드시트에 Apps Script 프로젝트를 연결합니다.
3. Apps Script 프로젝트 설정에서 시간대를 `Asia/Seoul`로 설정합니다.
4. Script Properties에 다음 값을 입력합니다.

| 키 | 내용 |
| --- | --- |
| `TEACHER_PASSWORD` | 교사 비밀번호 |
| `TOTAL_SEATS` | 전체 좌석 수 |
| `PERIOD_1_START_TIME` | 1교시 시작 시각 (`HH:mm`) |
| `PERIOD_2_START_TIME` | 2교시 시작 시각 (`HH:mm`) |
| `PERIOD_3_START_TIME` | 3교시 시작 시각 (`HH:mm`) |

5. 스프레드시트에서 **스공시 관리 → 시트 초기화 및 검사**를 실행합니다.
6. `학생명단`과 `명부`를 입력한 뒤 **학생 명단 적용**을 실행합니다.
7. `pnpm check`로 정적 검사를 수행하고 `pnpm deploy`로 배포합니다.

## 시트 입력

시스템은 다음 시트를 사용합니다.

- `학생명단`: A 학번, B 이름, C 전화번호 뒤 4자리
- `명부`: A 학번, B 좌석번호, C:N 월~목 1~3교시 신청 여부
- `설정`: 미운영 날짜와 사유
- `교사`: 날짜별 교사 정보
- `기록`: 출결 변경 기록
- `미신청자`: 교사가 관리하는 별도 출결 목록

`명부`의 O열과 P열 이후 출결 열은 시스템이 관리합니다. 전화번호 뒤 4자리는 `0123`처럼 네 자리 문자열로 입력합니다.

## 학생 사용

1. 웹 앱에서 학생용을 선택합니다.
2. 학번과 전화번호 뒤 4자리로 로그인합니다.
3. 결석할 날짜를 선택해 등록하거나 취소합니다.
4. 사용 후 로그아웃합니다.

## 교사 사용

1. 웹 앱에서 교사용을 선택하고 비밀번호를 입력합니다.
2. 날짜와 교시를 선택해 좌석 출결을 확인합니다.
3. 좌석을 선택하고 저장합니다.
4. 미신청자는 검색해 목록에 추가한 뒤 별도로 저장합니다.
5. 상단 교사 입력은 오늘 정보를 저장합니다.
6. 사용 후 로그아웃합니다.

오늘 운영일만 출결을 수정할 수 있으며, 과거와 미래 날짜는 조회만 가능합니다.

## 운영

- 시간대는 Apps Script와 스프레드시트 모두 `Asia/Seoul`로 유지합니다.
- 최초 설정 후 **일일 트리거 설치**를 실행합니다.
- 배포 전 `pnpm check`, 배포 시 `pnpm deploy`를 사용합니다.
- 배포 후 실제 학생·교사 로그인과 출결 흐름을 확인합니다.
- 일일 자동 작업과 미신청자 저장은 시트 범위를 묶어 처리하므로 운영 중 해당 시트의 행·열 구조를 임의로 변경하지 않습니다.
- `.clasp.json`은 로컬 전용이며 커밋하지 않습니다.
